# CareerPilot Local 0.2.0 preview

## New reusable multi-source package

- Candidate-owned CV import (PDF/DOCX/text), role filters, full portfolio links and confirmed answers.
- Search public Remotive/RemoteOK/WWR/Himalayas feeds, configured ATS boards and recent public Telegram posts.
- Opt-in browser submissions to supported Lever/Ashby/Greenhouse and Google Forms workflows.
- Personal Telegram applications with OS-keyring sessions and outgoing-message readback.
- Private owner bot: local Ollama conversation, bounded search/apply/status/pause actions.
- Optional replies in already contacted Telegram application conversations.
- Dry-run default, application ledger reservations, no blind uncertain retries, persisted Telegram limits, confirmation-only notifications.
- CLI daily scheduler and documented Windows Task Scheduler invocation.

## Verification and limits

Tests use fictional profiles, mocked Telegram transport and browser fixtures with **all network routes intercepted**. They do not constitute live employer application proof. The multi-source package is beta; custom controls, CAPTCHA, legal agreements, unknown facts, uploads, account registration and unsupported routes can require a person. No paid applications, universal account provisioning or CAPTCHA bypass. HH retains its own configuration and daily limit.

Private CVs, account secrets, browser profiles, conversations and application history are not included. See the README and `docs/MULTISOURCE.md` before opt-in.
