# Security

Never publish tokens, private profiles, CVs, databases, logs or browser cookies. Revoke any disclosed credentials through their issuing services.

Report vulnerabilities through GitHub private vulnerability reporting when available. Otherwise open a minimal issue requesting a private reporting channel, without exploit details or sensitive data.

This public preview is not a security-audited product. A local model is not a security boundary. Employer text is untrusted; authorization must be enforced by code. Do not disable platform protections.
